# Page-saving extension

A Chrome extension that saves a web page or a podcast transcript from YouTube as an AI-written note in your second brain.

Why I built it: see [the extension readme](page-saving-extension/readme.md).

- [`page-saving-extension/`](page-saving-extension/readme.md): setup and use. It saves a web page as an AI-written note in a GitHub repo or a Notion database.
- The extension needs an AI API key.
