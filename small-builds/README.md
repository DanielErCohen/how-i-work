# Small builds

Two small tools:

- [`page-saving-extension/`](page-saving-extension/readme.md): a Chrome extension that saves a web page as an AI-written note in a GitHub repo or a Notion database.
- [`voice-transcriber/`](voice-transcriber/readme.md): a local Whisper transcriber for voice notes that writes a markdown note.

The extension needs an AI API key. The transcriber runs offline on Apple Silicon.
