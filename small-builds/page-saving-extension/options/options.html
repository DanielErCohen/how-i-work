Second Brain Settings

Configure your AI model, and GitHub and Notion destinations.

Version 2.2.0 · Last updated Oct '26 · Use any AI provider with an API key

AI model

Exact model ID as the provider names it. The default is only a starting point: check the provider's model list.

Filled in by the provider. Change it for a custom or self-hosted endpoint (for example http://localhost:11434/v1 for Ollama).

OpenAI-compatible calls /chat/completions; Anthropic-compatible calls /v1/messages.

GitHub

Use a fine-grained token scoped to one repo, with Contents set to read and write. Use a private repo: captures can include email threads. Create at github.com/settings/personal-access-tokens/new

Save each capture to more than one repo. One per line as owner/repo or owner/repo@branch (branch defaults to the one above, then main). The same token must have access to each.

Notion

Create an integration at notion.so/my-integrations, then share your database with it.

From your database URL: notion.so/<workspace>/{database-id}?v=...

Default Destination

The popup lets you tick any combination of repos and Notion. This sets which is pre-selected when only one is configured, and whether Notion is pre-ticked.

Article Categories

The model automatically picks one of these categories for each capture:
ai-llms · product · entrepreneurship · leadership · tools-tech · self-improvement · misc

Articles land in 02-areas/saved-articles/{category}/ on your repo. No inbox - straight to the right place.
