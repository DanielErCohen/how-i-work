# Test a clearer setting label

Made-up teaching example. The product, participants, observations and counts below were invented for this file.

## Position

Test the import setting's label before adding a setup checklist. The made-up evidence points to a naming problem.

## Evidence

In an invented usability session, three of five participants asked what "Bring your workspace" meant. Two of those three found the setting after the facilitator called it "Import a file". This is a small, prompted study; it does not show how often real users encounter the problem.

## Strongest counter

The label may explain only the first obstacle. Participants could find the setting and still fail to complete an import. Changing the label would leave that problem unresolved.

## Test

Give six new made-up participants the same sample file and ask them to import it without help. Three see the current label; three see "Import a file". Record whether each person finds the setting and completes the import. Keep the new label in the next prototype only if all three find it and finish without help while fewer than three do with the current label. Otherwise, inspect where they stop before choosing the next change.

## Decision

Test the clearer label because the available observation concerns naming. The result will choose the next prototype; this small exercise cannot establish a conversion lift.
