# decisions

One page per decision that changes what we build. Never rewrite a record. A new record supersedes the old one and links back.

Name files `YYYY-MM-DD-name.md` and use [`_template.md`](_template.md).

For a single decision outside a repo, use [templates/decision-record.md](../../decision-record.md).

Keep a one-line index at the bottom of this file:

```
- YYYY-MM-DD name - the call in one line - status (open, decided, superseded by <file>)
```
