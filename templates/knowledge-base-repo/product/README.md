# product

The product's current truth in three files:

- `problem.md`: who has the problem, when, what they do now. One page.
- `landscape.md`: the alternatives people use today, including doing nothing. Each row links to a research file.
- `product-doc.md`: what the product is and does. It wins any disagreement with a spec or a PR.

Edit these files in place. Do not keep earlier versions: git has them.
