# research

One file per question, named `YYYY-MM-DD-topic.md`.

```
# <Question>

Date: YYYY-MM-DD
Question: <one line>

## Answer
<At most three bullets.>

## Evidence
- <claim> - <source URL>, <source date>. <unit on every number>

## Uncertain
<What is still open and the cheapest way to settle it.>
```

A single source is a lead. Write "one source" next to it until a second one confirms.
