# Templates

Start with the [decision record](decision-record.md) for one decision, or copy a repository skeleton below and fill in its placeholders.

- [`knowledge-base-repo/`](knowledge-base-repo/README.md): prose. Research, decisions, specs, sprints, analytics, legal.
- [`code-repo/`](code-repo/README.md): code, plus the docs that go stale when the code changes.

Rule for where a doc goes: it belongs in the code repo if it goes stale when the code changes.
